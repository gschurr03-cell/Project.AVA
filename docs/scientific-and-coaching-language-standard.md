# Scientific and coaching language standard

AVA distinguishes observation, estimate, heuristic, comparison, hypothesis and projection.
It uses association and uncertainty, never diagnoses weakness/injury, assigns causation,
guarantees improvement, predicts injury, clears return to play or prescribes treatment.

Muscle-group language describes groups commonly involved in a pattern and states that
strength, timing, mobility or technique requires additional assessment. Predictions expose
assumptions, unknowns, timeframe and uncertainty. Automated prohibited-phrase checks are a
floor; qualified human review remains required.
