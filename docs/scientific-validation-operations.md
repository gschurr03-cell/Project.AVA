# Scientific validation operations

## Error taxonomy

Codes use recording, calibration, athlete-selection, pose, contact, timing, spatial,
derived-metric, confidence, benchmark, interpretation, recommendation, priority, wording,
version and UI-presentation families. Every failed case retains input/version/reference,
reproducibility, severity, affected visibility and owner. Recurring failures are attributed
to input quality, unsupported scenario, algorithm/model/threshold, calibration,
synchronization, contract/cache/UI, annotation or reference—not merely patched at display.

## Manual review

Review is required for ambiguous athlete/gates/calibration, low quality, inconsistent
metrics, high-value competition use, unusual asymmetry, model/reference disagreement,
high-impact coaching action or coach request. Original output and annotations remain
immutable; adjudication creates a versioned revised result with reviewers and rationale.

## Issue and change control

Scientific issues record severity, versions, affected surfaces, reproducibility, owner,
remediation, regression fixture and release impact. Metric definitions, thresholds,
confidence, benchmarks, predictions, Root Cause, recommendations, priorities and training
mappings require evidence, science reviewer, expected deltas, regression results, rollout
and rollback. Unexplained locked-holdout drift blocks promotion.

## Incidents

Wrong athlete, mixed manifest, materially incorrect high-confidence result, unsafe
recommendation, diagnosis language, misleading prediction, benchmark mismatch, hidden
metric exposure or validation-data leak may require hiding the metric, disabling the
version, manual review, reprocessing, claim correction or beta suspension. No live
scientific dashboard/incident workflow is deployed.

## Validation privacy and external review

Media stays private, consent-scoped, anonymized, access-controlled and separately authorized
for publication/marketing. External review packages include claims, definitions, protocol,
dataset description, results, exclusions, limitations, failures, visibility policy and
unresolved questions. Internal review is never described as peer review.
