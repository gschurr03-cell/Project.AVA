# Definition of complete

Verified Complete requires implementation, relevant builds/tests, real producer-consumer
connection, security review, scientific review when applicable, updated documentation,
linked evidence, no known regression and tracker update. Depending on the task it also
requires staging deployment, physical device, independent scientific comparison, coach
review, restore or rollback evidence.

Code, schema, fixture, document or green compilation alone is insufficient. Partial evidence
keeps the task In Progress.
