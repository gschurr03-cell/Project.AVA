# Task evidence standard

Acceptable evidence includes an intentional commit/diff, exact paths, passing command output,
remote CI run, deployment/version/URL, migration log, trace/request ID, redacted screenshot,
device/build details, study result, reviewer record, restore log and rollback record.

Evidence must state environment/date/version and must not contain secrets, tokens, signed
URLs, athlete identity, private report text or raw health/safety data. Links must be durable.
