# Analysis result contract

The canonical result is versioned and immutable after activation. It separates measured
values, derived/inferred observations, unavailable metrics, confidence, limitations,
recording quality, evidence, associated muscle groups, interventions, retest guidance and
artifact references.

Unsupported values remain null/availability-tagged. Peak velocity and other unaccepted
claims remain hidden. A failed analysis cannot expose partial calculations as validated
results. Provenance records the input/pipeline/model/metric versions and 60 FPS analysis
clock.
