# Prioritization and sizing standard

Priority: P0 immediate root blocker; P1 closed-beta blocker; P2 beta quality; P3 public
launch; P4 postlaunch; P5 optional. Severity: S0 catastrophic; S1 critical; S2 high; S3
medium; S4 low; S5 cleanup.

Security/data-isolation and athlete-safety S0/S1 work may be promoted. A P0/S3 integration
dependency can precede P2/S1 work when it unlocks all validation. Cosmetic work never
outranks data loss, authorization, scientific correctness or the core flow. Changes require
documented rationale in tracker history.

Sizing: XS < half day; S half to one day; M one to three days; L three to five days; XL
more than five days and normally decomposed before commitment. Estimates are planning
ranges, not promises.
