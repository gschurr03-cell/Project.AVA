# Root Cause review rubric

Reviewers score whether AVA: identifies an observable pattern; labels inference; includes
alternatives and missing evidence; uses confidence; avoids strength/injury diagnosis and
causation; qualifies muscle groups; requests additional assessment; and provides an
actionable, proportionate next step. Each dimension is accept, edit, reject or insufficient
context with a reason.

Approved phrasing includes “can be associated with” and “commonly involved in.” Statements
such as “your hamstrings are weak,” “your calves caused this,” or “you have an imbalance”
are rejected without a separate validated assessment.
