# Coaching memory

Coaching memory is typed evidence, not generated prose. Current fixture logic derives
exercise tolerance or adverse-response associations. One item is `candidate`, two
comparable items are `emerging`, and three are `established`; contradictory evidence lowers
confidence and marks contradiction. Memories become stale after 90 days and retire after
180 days unless reconfirmed.

Every item retains source event IDs, count, date range, confidence, status, contradiction,
review date, and scope. One isolated event cannot become established. Taper, adherence,
phase, objective, recovery, preference, and coach-decision memory types are contracted but
require additional domain reducers and coach validation before use.
