# Coach review workflow

Review actions are approve, reject and request modification. Structured coach changes may
adjust exercise, dosage, schedule or objective allocation but must record original/new
value, reason, reviewer, timestamp, validation, fingerprint change and reapproval.
Clinician restrictions and hard safety constraints cannot be overridden.

The server service enforces owner/athlete scope and reviewer role. There is no durable
review database or UI; therefore no plan in this implementation is actually coach approved.
