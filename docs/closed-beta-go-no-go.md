# Closed-beta go/no-go

Decision date: 2026-07-18. Decision: **NO-GO**.

Proposed future scope is a small allowlisted adult-athlete/authorized-coach cohort using 60
FPS-class capture, real analysis, reports, and coach-approved deterministic training only.
Excluded: minors, autonomous plan activation, medical/rehabilitation use, experimental
authoritative metrics, public access and unsupported devices.

Blocking risks: no deployed isolated staging/beta, managed secrets, distributed abuse
control, centralized telemetry/alerts, tested backup restore/rollback, complete
authorization matrix, signed native/device evidence, operational deletion, professional
privacy/consent review, or assigned incident/support coverage.

Rollback design exists but has not been rehearsed. Suspension triggers include any
cross-athlete access, safety-event loss, unapproved/stale plan execution, manifest mismatch,
material privacy issue, data loss or unexplained scientific drift.
