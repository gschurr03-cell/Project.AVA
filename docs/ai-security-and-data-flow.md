# AI security and data flow

Authoritative biomechanics, recommendations, priorities, projections, and training plans are
deterministic and provider-free. Optional LLM coaching is disabled. No text model receives
raw video or may activate a result/plan, approve training, override a restriction, or
diagnose injury. Any future provider must minimize fields, use versioned prompts, strict
schemas, bounded timeouts/retries/cost, documented retention, and fail-safe degradation.
Uploaded/free-form content is data and cannot alter system authority.
