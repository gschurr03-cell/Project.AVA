# Sprint exercise library v1

The governed catalog now contains more than 40 deterministic entries covering starts,
acceleration, resisted/hill work, fly/wicket/ins-and-outs, endurance, tempo, technical
strides, plyometrics, common strength/power lifts, mobility and recovery. Each entry carries
objectives, dosage, cues, common errors, associations, facilities/equipment, training age,
restrictions, evidence IDs, progression/regression links and optional feature gate.

Depth jumps, resisted/hill sprinting, advanced maximum-velocity/special-endurance work and
Olympic-lift derivatives are gated. Catalog breadth does not prove universal appropriateness;
dosage remains internal-fixture policy pending qualified review.
