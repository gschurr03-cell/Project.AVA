# Coach Report design system

The report follows AVA’s existing premium system: carbon-black application background,
red AVA accent, restrained borders, high-contrast type, rounded panels, and compact
confidence labels. It uses semantic headings, navigation, article, and section elements.

The athlete projection emphasizes the executive summary, first priority, plain-language
action, and next capture. The coach projection exposes the same conclusions with the
longer interpretation explanation and evidence detail. Layout collapses to one column on
small screens. Print mode uses ink-safe black-on-white styling and hides interactive
controls.
