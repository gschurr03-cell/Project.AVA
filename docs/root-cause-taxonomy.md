# Root Cause Taxonomy

Version `ava-root-cause-taxonomy-v1` provides extensible non-clinical limiter keys:
force production, projection, front/back-side organization, pelvic control, posture, hip
mobility, ankle stiffness, contact quality, elastic return, rhythm, arm timing, trunk
stability, coordination, relaxation, symmetry, acceleration, maximum velocity,
transition, deceleration, and unknown.

Catalog membership does not assert that a limiter exists. A hypothesis requires explicit
structured interpretation links and evidence. `unknown` is a valid, preferred result when
available evidence cannot distinguish explanations.

Interpretations are separately classified as root cause, primary symptom, secondary
symptom, likely consequence, independent finding, or unknown relationship.
