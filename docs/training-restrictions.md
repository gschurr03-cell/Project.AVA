# Training restrictions

Restrictions carry authority, body region, prohibited/permitted categories, maximum
intensity/volume, effective/review/expiry dates and explicit clearance status. Precedence
is clinician → organization → coach → athlete for competing restrictions, while the full
rule order is clinician, safety, acute symptom, competition, coach, schedule, readiness,
primary, secondary, maintenance, preference, variation. Lower authority never silently
overrides higher authority.
