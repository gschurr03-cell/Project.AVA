# iOS beta information architecture

- **Home:** current focus, top opportunity, latest status, action required, next assessment,
  and latest activated report.
- **Analyze:** capture/import entry and analysis history/status. Submission order is not
  treated as activation order.
- **Progress:** backend-classified comparable series, coaching-state change, and accessible
  text summaries.
- **Coaching:** backend-ordered recommendations, priority rationale, optimization, root
  cause, evidence and confidence.
- **Profile:** athlete/account preferences and privacy; intelligence conclusions are read-only.

Analysis detail orders overview, recording quality, findings, priorities, possible causes,
recommendations, optimization, benchmark, projection, evidence/confidence and provenance.
One manifest-scoped package supplies all sections. Progressive disclosure separates athlete
summary from coach-authorized technical detail.
