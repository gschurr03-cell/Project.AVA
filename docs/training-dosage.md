# Training dosage

Discriminated contracts separate sprint, lifting and recovery semantics. Sprint dosage
uses sets/repetitions/distance/intensity/rest/surface/start/stopping rule. Lifting uses
sets/reps, percent-1RM/RPE/reps-in-reserve/bodyweight, load, rest, tempo and stopping rule.
Recovery uses duration and low intensity. Bounds reject negative rest, invalid load method,
excessive distance/repetitions and missing non-bodyweight load values.
