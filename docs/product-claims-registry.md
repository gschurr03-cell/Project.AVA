# Product claims registry

| Claim | Allowed wording/status | Prohibited wording |
| --- | --- | --- |
| Biomechanics analysis | “AVA estimates selected sprint timing and 2D movement measures under supported recording conditions.” Internal/coach only. | “Scientifically proven biomechanics lab” |
| Timing/velocity | “Reference validation is in progress; compatible results may require review.” | Specific accuracy guarantee |
| Limiter detection | “AVA surfaces evidence-linked possible movement limitations.” | Definitive root cause/weakness |
| Muscle groups | “This pattern can be associated with…” | Weakness, imbalance or causation |
| Recommendations | “Suggested coach-reviewable intervention and retest.” | Guaranteed improvement/treatment |
| Projection | “Evidence-bounded scenario with uncalibrated uncertainty.” Experimental. | Guaranteed PB/future potential |
| Training | “Deterministic draft requiring approval.” | Autonomous or medically personalized plan |

Science/product/legal review and evidence expiry are not assigned; no public scientific
marketing claim is approved.
