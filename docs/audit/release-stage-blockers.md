# Release-stage blockers

## P0 before closed beta

1. Commit/review a reproducible product baseline.
2. Provision isolated staging/beta web, Supabase and worker environments with managed secrets.
3. Apply migrations and prove ownership/storage/RPC denial in staging.
4. Implement the versioned mobile API and connect native capture/upload/result.
5. Execute one real 60 FPS-class end-to-end workflow on a physical supported iPhone.
6. Deploy monitoring/alerts and rehearse failure, dead-letter, restore, rollback and deletion.
7. Establish an eligible consented reference dataset and keep unvalidated outputs hidden.
8. Complete professional security/privacy and coach safety review.

## Athlete beta additions

Coach-approved training persistence/execution, comprehension study, notification/safety-event
handling, offline stale-plan rules, accessibility/device matrix and support coverage.

## App Store/public additions

Real bundle IDs/signing/archive/TestFlight, store assets/privacy labels/account deletion,
public rate/abuse controls, scale/cost tests, legal approval and broader scientific evidence.
