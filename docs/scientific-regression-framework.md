# Scientific regression framework

Every proposed engine version runs immutable fixtures and compares metric values,
availability, failures, confidence, recommendations, priorities, projections and report
language against the active version. Changes are expected improvement, neutral, explained
tradeoff, unexplained drift, regression or blocker. Locked-holdout failures and unexplained
material drift block promotion.

Shadow outputs remain nonauthoritative, versioned and fingerprinted; they cannot reach
reports, plans or athletes. Existing orchestration shadow contracts provide architecture,
but no scientific candidate-versus-active study has run.
