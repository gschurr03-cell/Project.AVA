# Opportunity Cost Model

Performance optimization funds no more than two improvement focuses. All other eligible
focuses are explicitly deferred and remain visible to Adaptive Coaching as monitoring
work.

For each selected focus, the state records the best deferred alternative, deterministic
score difference, and a template explanation. This is a relative allocation comparison,
not a monetary cost or promised performance gain.

Maintenance and monitoring are not charged against the two-focus limit. Repeated
investment reduces future return through prior exposure, captured benefit, plateau
evidence, and adaptation profile. A deferred focus can overtake a current focus after new
evidence, changed season/competition context, measured adaptation, or a structured coach
override.
