# Coach decision memory and athlete preferences

Coach decisions are structured events with plan scope and provenance; one override does
not become permanent memory. Durable decision rules still need explicit effective dates,
expiry, and a persistence workflow.

Athlete training/rest-day, duration, equipment, environment, unit, and notification
preferences are soft preferences. They never override safety, clinician authority, hard
recovery, competition protection, or authorization. Constraints, restrictions, and
preferences must remain distinct.
