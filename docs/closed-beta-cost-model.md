# Closed-beta cost model

Cost instrumentation is not live. Required dimensions are web/worker compute, database,
storage/retention, egress, backups, telemetry, notifications and native distribution.
Measure per upload, eligible analysis, report, active athlete/coach and plan cycle in staging.

The largest variable is CPU video processing plus storage/egress. Establish provider prices
and measured worker seconds/GB before assigning dollar estimates. Configure daily/monthly
budget alerts and per-athlete analysis quotas. Do not reduce scientific validation to meet
an unmeasured cost target.
