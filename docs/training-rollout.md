# Training programming rollout

Rollout remains `DISABLED` by default. The highest permitted state for this phase is
internal draft generation. Catalog expansion, progression code and coach-review contracts
do not authorize athlete delivery.

Required gates are durable owner-scoped persistence, audited review/override APIs, catalog
and dosage review by qualified sprint/strength coaches, clinical restriction governance,
real orchestration shadow runs, adherence/event integrity, load safety calibration and a
bounded monitored coach-reviewed beta.
# Longitudinal rollout (14C)

`TRAINING_LONGITUDINAL_MODE` is independent of the weekly-program flag and defaults to
`DISABLED`. Allowed stages are fixtures only, state only, shadow adaptation, internal
coach review, approved internal athlete plan, bounded beta, and production. No stage
permits autonomous activation or approval bypass. This implementation is `FIXTURES_ONLY`
in evidence even while the configured default remains disabled.
