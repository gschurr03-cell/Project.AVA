# Training plan explainability and provenance

Each material decision stores explanation, rule IDs and source IDs. The vertical slice
explains phase, primary objective and weekly placement; each session/exercise stores its
rationale and rules. Plans retain manifest, upstream snapshots, catalog/rule/engine/
validation versions and deterministic input/plan fingerprints.

Future substitutions, taper modifications, readiness changes, deferred objectives and
coach overrides must carry the same provenance. Explanations summarize deterministic
decisions and are never a planning source.
