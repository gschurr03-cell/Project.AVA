# Program effectiveness

Effectiveness must combine objective progress, adherence, quality, tolerance, competition
context, readiness stability, adverse response, coach satisfaction, athlete acceptability,
and feasibility. The deterministic evaluator returns likely effective, partially effective,
unclear, likely ineffective, or unsafe/unsuitable from labeled dimensions. Repeated adverse
response dominates the result. Every result requires review; it is not reduced to a
personal best and cannot activate a plan.
