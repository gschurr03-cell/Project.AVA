# User onboarding

`/onboarding` contains five concise steps: measured outputs, recording setup, useful profile
context, result review, and the scientific boundary. State is persisted in `onboarding_states`
with current step, state, content version, acknowledgement, completion date, and update date.

Optional education may be dismissed. The scientific acknowledgement is required to mark the
flow complete. Users can reopen the flow from Help or Account. A new onboarding version can
place users into `needs_reconfirmation`; the current version is `ava-web-beta-onboarding-v1`.

Beta tester path: create an athlete, review `/help/recording`, upload MP4/MOV/M4V footage no
larger than 512 MB or 60 seconds, confirm geometry in Timing Workspace, submit analysis, and
use `/support` with the displayed reference when recovery guidance is insufficient.
