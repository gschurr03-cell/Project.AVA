# iOS Coach Report

The native report displays the activated executive summary, findings, strengths, limiters,
priorities, observations, possible contributing factors, unknowns, evidence requests,
confidence and provenance in backend order. Measured values, interpretations, associations
and unknowns have separate labels. SwiftUI headings, disclosure groups and Dynamic Type
provide the initial accessible structure.

No language is generated or rewritten on-device. Sharing/PDF remains disabled by default
until privacy, role filtering and deterministic export are validated.
