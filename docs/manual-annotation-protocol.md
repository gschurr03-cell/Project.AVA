# Manual annotation protocol

Annotators select the first frame meeting the locked zone/contact/toe-off definition and
record frame, source timestamp, confidence, occlusion, athlete identity and unusable state.
Zone entry/exit uses the same body/gate crossing definition as AVA and the reference block.
Contact is first visible/reference-supported ground contact; toe-off is last supported frame
before flight. Ambiguity is labeled, not guessed.

Two independent reviewers annotate validation/holdout items. Adjudication creates a new
version and preserves both originals. Report absolute frame disagreement, timestamp
disagreement, event agreement and an appropriate ICC/kappa only after assumptions are met.
No inter-rater result exists yet.
