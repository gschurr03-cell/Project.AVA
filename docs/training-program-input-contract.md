# Training Program input contract

`TrainingProgramInput` v1 includes owner/athlete identity, authoritative manifest,
adult sprint profile, upstream snapshot references, sourced objectives, season/availability/
facilities/equipment, competitions, current readiness, authority-bearing restrictions,
recent multidimensional exposure, history and approval requirement. Every readiness or
restriction signal has provenance and validity.

Missing or unsafe data does not receive a normal default. V1 supports adult 60/100/200/400 m
contexts only; youth, rehabilitation/return-to-play, medically unresolved athletes and
unsupported events fail closed.
