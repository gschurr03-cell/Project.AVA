# Scientific validation framework

Analytical validity compares the intended variable to a compatible reference. Technical
reliability measures repeated-output agreement. Reproducibility requires the same version,
input, calibration and manifest to reproduce a material fingerprint. Robustness tests the
predeclared operating envelope. Coaching validity uses qualified blinded review. Product
usability measures coach/athlete comprehension. Safety validity audits rejection,
confidence, association language and unsupported conclusions.

Evidence levels are internally tested, fixture validated, benchmark/reference validated,
coach reviewed, athlete comprehension tested, externally reviewed and independently
replicated. A lower level never implies a higher one.
